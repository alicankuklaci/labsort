Description

Short: A calm liquid sorting puzzle with 250 handcrafted levels across 8 glowing laboratories, plus live 1v1 duels. No ads, no timers.

Lab Sort is a liquid sorting puzzle set in a cozy, glowing laboratory. Pour colorful liquids between glass vials until each one holds a single color. It starts gentle and grows into real brain-teasers, with 250 handcrafted levels spread across 8 labs, each with its own look and objects on the shelves.

Every level has been checked by a solver, so every puzzle can be solved and the star targets are always reachable. When you want company, Duel mode puts you in a live 1v1 race against another player: same puzzle, first to sort wins. There are no ads and no timers in the main game, so you can play at your own pace.

Features

  • 250 handcrafted levels across 8 themed laboratories
  • Live 1v1 duels and a global leaderboard through Game Center
  • No ads and no timers in the main game
  • Undo, hints and an extra vial when you get stuck
  • Daily rewards and collectible vial skins
  • Color-blind mode with symbols on every liquid
  • Playable in 8 languages
